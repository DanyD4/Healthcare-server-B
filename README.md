# HealthCare Application

## Projektbeskrivning
HealthCare-applikationen är framtagen för att förbättra kundupplevelsen genom att förenkla och digitalisera bokningsprocessen mellan patienter och vårdgivare.
Applikationen erbjuder säker autentisering, smidig bokningshantering och unika dashboards för både patienter och vårdgivare.

## Funktioner
- **Säkerhet och autentisering**: Implementerat med Spring Boot Security och JWT-token för att hantera användarautentisering och rollbaserad åtkomst.
- **Patientdashboard**: Ger patienter tillgång till sin personliga profil och bokningsöversikt.
- **Vårdgivardashboard**: Möjliggör för vårdgivare att hantera tillgängliga tider.
- **Bokning dashboard**: Patienter kan boka läkarbesök via ett användarvänligt gränssnitt.


## Installation och användning
1. **Klona projektet**:  
   `git clone https://github.com/DanyD4/Healthcare-server-B.git`
2. **Backend**:
   - Installera och starta projektet med Maven.
   - Kör Spring Boot-applikationen.
3. **Frontend**:
   - Navigera till frontend-mappen.
   - Installera beroenden med `npm install`.
   - Starta applikationen med `npm start`.

## Teknikstack
- **Backend**: Java, Spring Boot, Spring Security, JWT, MongoDB, Maven
- **Frontend**: React, JavaScript, Vite, Axios
- **Verktyg för testning**: Postman, GitHub Actions
